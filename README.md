## 🛠️ Team Workflow & Git Standards

> **Before making changes:** Review [`SOP.md`](./SOP.md) for our team's branching, naming, and pull-request standards.

* **Sync First:** Always click **Fetch origin → Pull origin** in GitHub Desktop before opening or editing shared folders to prevent merge conflicts.

* **Keep Weekly Docs Scoped:** Place individual assignment write-ups and test tables inside their respective weekly folders (e.g., `12-Week-12-Independence-Day/README.md`).

* **Unity Build Hygiene:** Temporary build and cache folders (`Library/`, `Temp/`, `Obj/`, `Logs/`, `UserSettings/`) are ignored via `.gitignore`—never force-add generated caches.
